# 基于合成数据增强与知识蒸馏的英语作文智能批改系统

> **项目简介**：以 Qwen2.5-0.5B 为学生模型，通过合成数据增强、离线响应知识蒸馏和 QLoRA 多任务监督微调（SFT），开发英语作文智能批改系统，研究高质量合成反馈能否改善小参数模型的垂直领域适配能力。

## 📁 目录结构说明

```text
essay-review/
├── data/
│   ├── raw/          # 原始数据集（ELLIPSE / LEAF / W&I+LOCNESS）
│   ├── processed/    # 清洗、划分后的原始数据
│   └── synthetic/    # 教师模型合成的数据（未筛选/筛选后）
├── synthesis/        # 教师生成、质量筛选脚本
├── training/         # QLoRA、多任务 SFT、蒸馏训练代码
├── evaluation/       # 自动指标与人工评价脚本/表格
├── inference/        # 模型推理接口与输出校验
├── web/              # Gradio 网页前端代码
├── configs/          # Prompt 模板与训练超参数配置
├── results/          # 训练曲线、评测图表、典型案例
├── docs/             # 项目规范文档（数据Schema、接口定义等）
└── README.md
```

## 🛠️ Git 协作规范（所有人必读）

为了保证项目顺利集成，请所有人严格遵守以下开发规范：

1. **分支管理**：绝对**不允许**直接在 `main` 分支上提交代码。所有人必须在自己的分支（如 `feat-data-processing`）上开发，完成后提交 Pull Request (PR)，由 1 号审查后合并。
2. **密钥安全**：**严禁**将大模型 API Key、Token 等敏感信息上传至 GitHub。请在本地使用 `.env` 文件配置，并确保 `.gitignore` 中包含了 `.env`。
3. **大文件处理**：**严禁**将模型权重（如 `.bin`, `.safetensors`）、大型数据集（如 `.csv`, `.jsonl`）直接推送到 GitHub。大文件请统一上传至网盘或使用 Git LFS，并在群内共享链接。
4. **提交信息**：Commit message 请尽量清晰（如：`feat: 添加数据清洗脚本`, `fix: 修复推理接口报错`）。
