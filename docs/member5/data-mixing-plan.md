# 成员 5：多任务数据混合方案草稿

状态：第一周讨论稿。数量来自本地 training_data_v1 训练文件核对；以下组织与采样方式为建议，尚未作为正式训练配置执行。

## 1. 当前可用的原始训练数据

必须共同读取 train-00001.jsonl 与 train-00002.jsonl。

| 任务 | 来源 | 条数 | 回答结构 |
|---|---|---:|---|
| 评分 essay_scoring | ELLIPSE | 3520 | scores 对象，六维小数评分 |
| 人工反馈 essay_feedback | LEAF | 4018 | feedback 字符串 |
| 纠错 grammar_correction | WI_LOCNESS | 1714 | corrected_text 字符串，完整纠正文本 |
| 合计 | | 9252 | |

每条记录已有 user / assistant 两条 messages。user 给出对应任务的要求和原文，assistant 给出该任务答案。混合训练指打乱不同任务的样本供同一个模型学习，不把不同作文的标签拼在一起，也不要求每篇作文同时具有三个任务标签。

## 2. 建议的第一版组织方式

- 原始样本保持内容不变，保留 ID、来源、任务与 split。
- B 使用上述原始训练数据。
- C 使用同一份原始训练数据，加 N 条 C 池教师反馈。
- D 使用同一份原始训练数据，加 N 条 D 池教师反馈。
- N 由最终可用候选数量与训练预算确定，目前不写死。C/D 等量不要求源作文逐条配对，需记录源作文重合及长度分布。
- 教师反馈只能来自训练作文，不能使用验证集或测试集生成训练标签；不能用教师分数替换人工评分。
- 构造训练数据时，只从明确指定的 train 文件读取。验证与测试文件单独管理，不参与训练混合。

## 3. 当前讨论中的采样与预算方案

拟采用评分、反馈、纠错按 1:1:1 采样，保留全部原始样本，不通过删数据凑三等份。B 的反馈来自 LEAF；C/D 的反馈任务内部暂建议人工与教师按 1:1 采样，因此整体分别为评分 1/3、人工反馈 1/6、教师反馈 1/6、纠错 1/3。

该比例仍需与 4 号确认，不代表用户已批准最终训练配置。C/D 合成候选数量相同；具体 N 待可用数据与预算确定。

三组从同一原始 Qwen 分别训练，固定有效批量与参数更新步数，记录实际处理 token、参与损失的回答 token、各任务采样次数及截断比例。步数通过小规模试跑确定，不直接固定相同 epoch。固定任务比例与更新预算下，研究的是把部分人工反馈采样机会分配给教师数据是否有帮助。

## 4. 已确定：人工与教师反馈使用同一种 LEAF 格式

用户决定教师直接模仿 LEAF。共用任务指令为：

```text
Provide feedback on the following English essay. Return a JSON object with a feedback string.
```

接两个换行与原文，assistant 目标为 {"feedback":"一段英文反馈"}。不要求 summary、原文片段、corrected、explanation 或 suggestions 字段。

原始 LEAF 数据保持不变。新教师候选使用 schema_version=leaf_feedback_v1；导出的 messages 与 LEAF 的 user 指令和答案结构一致。不能将旧细粒度 JSON 直接包进字符串冒充新标签；旧批次不混入新实验。

C 为基础格式合格数据；D 为进一步人工内容审核接受的数据。新格式不能继续把引用位置、重复局部改法作为自动筛选依据；具体见 ../member3/data-contract.md。
