## 1. 实验要回答什么

1. B 与 C 比较：加入教师合成反馈后，学生模型的评分、反馈和纠错表现如何变化？
2. A 与 B 比较：原始人工标注数据微调，相比原始模型带来哪些变化？

分别报告各任务结果，不以单项提升代表全部任务提升。

## 2. 三组模型

| 组别 | 基础模型及训练数据 | 用途 |
|---|---|---|
| A | 官方 Qwen3-1.7B，不进行本项目微调 | 初始能力参考，保留格式失败记录 |
| B | 同一 Qwen3-1.7B＋原始人工标注数据，多任务 SFT | 基线，由 4 号负责训练 |
| C | 同一 Qwen3-1.7B＋原始数据＋基本格式合格的教师合成反馈，多任务 SFT | 检查加入合成数据后的变化，由 5 号负责 |

C 的“未深度筛选”仍要求基本格式合格。新教师标签统一 LEAF 的 feedback 字符串；原计划的 D 用于检验内容筛选的效果，此问题留待后续研究。旧细粒度数据只保留为历史版本，不与新批次混用。

## 3. 比较时需要控制什么

- B/C 使用相同版本的基础模型及共用训练框架；LoRA、优化器、学习率、序列长度、随机种子等配置原则上保持一致，例外必须记录原因。
- 原始数据版本及划分固定；验证集用于开发和选择配置，测试集留作最终评测，不用于合成训练数据或调参。
- 对 C 的教师样本记录来源、长度分布、Prompt 版本、筛选策略及实际审核情况；不同批次不能无说明混用。
- 明确原始数据与合成数据的采样方式，记录每组实际训练步数、有效训练 token 数及截断情况。相同样本数不等于相同训练量。
- B/C 实际训练均为 1,500 步、有效 batch 8、最大长度 512。B 的实际训练文件及是否重采样待 4 号确认。
- A/B/C 使用同一套评测样本、任务提示和输出解析规则；推理参数尽量一致，模型输入模板的必要差异须记录。

这些控制用于减少比较中的混杂因素；具体预算和采样比例尚未确定。

## 4. 评价方式

| 任务 | 评价方式 | 当前状态 |
|---|---|---|
| 评分 | ELLIPSE 六维分别计算 MAE、RMSE、QWK，并报告逐维指标的宏平均 | 初版已实现：保留小数，QWK 按实际分数距离二次加权；逐维失败处理及补充惩罚已落实 |
| 反馈 | ROUGE/BLEU、可选 BERTScore 辅助；沿用 6 号四维量表做内容评价 | 自动相似度和评审汇总已实现；本轮内容评价由 6 号组织 AI 裁判，外部评分可导入汇总 |
| 纠错 | ERRANT P/R/F0.5；全文单参考与已对齐多参考 M2 分开 | 两种入口已实现；当前测试包仍缺纠错测试参考，不能冒充官方 BEA 结果 |
| 输出可用性 | JSON 有效率、字段缺失、预测缺失及分数越界等 | 评分初版已逐维记录失败、覆盖率及原始输出；网页集成另行对接 |

评分保留 ELLIPSE 原始小数，六维为 cohesion、syntax、vocabulary、phraseology、grammar、conventions；不擅自构造作文总分。
