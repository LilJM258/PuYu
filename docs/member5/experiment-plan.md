# 成员 5：A/B/C/D 实验方案草稿

状态：第一周讨论稿。模型组别与研究问题沿用开发手册；具体训练配置、采样比例和接口尚待团队确认。本文件不是已完成实验的记录。

## 1. 实验要回答什么

1. B 与 C 比较：加入教师合成反馈后，学生模型的评分、反馈和纠错表现如何变化？
2. C 与 D 比较：在控制合成样本数量与训练预算后，质量筛选是否带来改善？
3. A 与 B 比较：原始人工标注数据微调，相比原始模型带来哪些变化？

分别报告各任务结果，不以单项提升代表全部任务提升，也不预设 D 一定最好。

## 2. 四组模型

| 组别 | 基础模型及训练数据 | 用途 |
|---|---|---|
| A | 原始 Qwen2.5-0.5B Base，不进行本项目微调 | 初始能力参考，保留格式失败记录 |
| B | 同一基础模型＋原始人工标注数据，多任务 SFT | 基线，由 4 号负责训练 |
| C | 同一基础模型＋原始数据＋基本格式合格的教师合成反馈，多任务 SFT | 检查加入合成数据后的变化，由 5 号负责 |
| D | 同一基础模型＋原始数据＋进一步质量筛选的教师合成反馈，多任务 SFT | 检查质量筛选后的变化，由 5 号负责 |

C 的“未深度筛选”仍要求基本格式合格。新教师标签统一 LEAF 的 feedback 字符串；D 从 C 中经人工内容审核接受后导出。旧细粒度数据只保留为历史版本，不与新批次混用。

## 3. 比较时需要控制什么

- B/C/D 使用相同版本的基础模型及共用训练框架；LoRA、优化器、学习率、序列长度、随机种子等配置原则上保持一致，例外必须记录原因。
- 原始数据版本及划分固定；验证集用于开发和选择配置，测试集留作最终评测，不用于合成训练数据或调参。
- C/D 的合成样本数量相同，记录来源、长度分布、Prompt 版本、筛选策略及实际审核情况；不同批次不能无说明混用。
- 明确原始数据与合成数据的采样方式，记录每组实际训练步数、有效训练 token 数及截断情况。相同样本数不等于相同训练量。
- B/C/D 的训练预算控制方式待与 4 号确认；必要时为 B 设置重复采样或等预算对照，避免把额外训练量的作用归因于合成数据。
- A/B/C/D 使用同一套评测样本、任务提示和输出解析规则；推理参数尽量一致，模型输入模板的必要差异须记录。

这些控制用于减少比较中的混杂因素；具体预算和采样比例尚未确定。

## 4. 评价方式

| 任务 | 评价方式 | 当前状态 |
|---|---|---|
| 评分 | ELLIPSE 六维分别计算 MAE、RMSE、QWK，并报告逐维指标的宏平均 | 初版已实现：保留小数，QWK 按实际分数距离二次加权；逐维失败处理及补充惩罚已落实 |
| 反馈 | 人工判断问题识别、建议具体性、修改有效性、原意忠实度及虚构错误 | 与 6 号确认评价流程 |
| 纠错 | 优先考虑 ERRANT F0.5，须先对齐预测和参考答案格式 | 当前测试包缺少带答案的纠错测试样本，需确认评测资源 |
| 输出可用性 | JSON 有效率、字段缺失、预测缺失及分数越界等 | 评分初版已逐维记录失败、覆盖率及原始输出；网页集成另行对接 |

评分保留 ELLIPSE 原始小数，六维为 cohesion、syntax、vocabulary、phraseology、grammar、conventions；不擅自构造作文总分。
