## 四、已确定的格式变更：教师反馈统一模仿 LEAF

### 决定及原因

LEAF 本身也是 JSON，只是反馈内容位于一个字符串中。此前把它称为“文字答案而不是 JSON”不准确。用户决定不采用按原文片段、改法和解释分字段的教师标签，直接沿用 LEAF 的任务要求和答案结构，减少人工与教师数据混合时的格式差异。

统一 user 指令如下，其后接两个换行与完整作文：

```text
Provide feedback on the following English essay. Return a JSON object with a feedback string.
```

统一 assistant 答案：

```json
{"feedback":"一段针对该作文的英文反馈"}
```

总体评价、问题说明与建议写在 feedback 文字中，不要求独立 summary、suggestions、original、corrected、explanation 或 errors 字段。保留原始 LEAF 数据，不为统一格式补造人工标签；评分、纠错仍是独立任务。

## 五、已确定的评分评价方向

ELLIPSE 六维为 cohesion、syntax、vocabulary、phraseology、grammar、conventions，评分范围 1～5，保留原始小数。逐维计算 MAE、RMSE、QWK，另给逐维指标宏平均，不自行构造作文总分。

- MAE：平均绝对误差，越低越好。
- RMSE：对较大偏差惩罚更重，越低越好。
- QWK：评分等级一致性，越高越好；现已采用实际分数距离的二次权重，保留小数，不取整或分箱，不把失败加成一个等级。

### 生成失败也必须影响整体评价

用户已同意以下方向，现已在评分初版程序中实现：

1. 保留原始输出，不在评测前将分数取整、截回范围、补齐字段或静默丢弃失败样本。
2. 在有效预测上报告标准 MAE、RMSE、QWK，同时明确样本数量与覆盖率。
3. 单独保留失败记录和原因，用于复查与判断失败率；它们不是评分答案。
4. 增加项目自定义补充指标“计入失败惩罚的平均绝对误差”：合法预测使用实际绝对误差，失败按 4 分误差计入，因为 1～5 合法评分范围的最大绝对误差为 4。
5. 该补充指标不能冒充标准 MAE，不把失败填成预测 1 分，也不把失败强塞进 QWK。

示例：100 次评分中 80 次有效，有效部分 MAE=0.5，20 次失败，则计入惩罚的平均误差为 (80×0.5+20×4)/100=1.2。这仅是规则算例，不是模型实测结果。

已确定并实现：按维度判断；一维失败不影响其他合法维度。重复预测 ID 的六维全部失败；额外 ID 单独记录且不扩大分母；无法解析的行保留原文，不按行序猜测 ID；缺失应评 ID 的六维失败。各维标准指标以该维有效配对为分母，失败惩罚以该维全部应评样本为分母。

多模型共同有效子集对照暂未实现，作为后续辅助功能，不阻碍单模型评分初版使用。不能用它替代全量覆盖率和失败惩罚。

## 七、2026-11-03 追加：评分评测初版已开发

用户明确要求所有分数保留小数，其余按逐维处理方案执行。本轮实现：

- 新增 evaluation/scoring.py、evaluation/__init__.py，使用 Python 标准库，不加载模型或联网。
- 从原始 messages 读取评分人工答案；模型预测按 ID 匹配，支持 raw_output 或未经修复的 scores，二者同时存在以原始输出为准。
- 输出 report.json、samples.jsonl、failures.jsonl、unassigned.jsonl、unknown_ids.jsonl，保留分母、覆盖率、原始失败记录及输入文件 SHA-256。
- QWK 使用实际分数平方距离与经验边际分布计算；半分等距网格上等价于完整网格的常规 QWK。任意合法小数按实际距离参与，不取整、分箱或压缩类别间距。该口径写入运行记录，不能与取整口径无说明比较。
- QWK 在相同常数且完全一致等无定义情况输出 null 与原因；宏平均显示参与计算的维度数。
- 新增 14 项专项测试，覆盖手算、任意小数、QWK 边界、部分/全部失败、重复 ID、坏 JSON、原始输出优先和命令行读写；全部通过；与现有模块一起运行共 61 项测试通过。
- 新增 evaluation/examples/ 两个合成示例文件；3 篇、18 维中故意设定 1 维越界，程序输出 17/18 有效维度和 2/3 完整有效篇数，MAE 宏平均约 0.05556，惩罚误差宏平均约 0.27778。仅为程序算例，不是模型性能。
- 更新 evaluation/README.md 和实验方案状态。本轮没有改动训练、合成、推理或网页代码。
