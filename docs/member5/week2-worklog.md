## 4. 评价口径与边界

- 保持 LEAF 的 feedback 字符串，不要求教师或学生生成新的细粒度字段。评审字段只属于评价记录。
- ROUGE/BLEU/BERTScore 是与参考反馈的相似度，不能当成建议正确率。内容判断仍沿用 6 号四维 1～5 分人工标准；汇总程序不会自动作出这些判断。
- 多人评分先在同一反馈内平均，再跨反馈平均。保留原始评分、N/A、分母及分歧；不代替人工裁决。虚构/误判率是独立评审记录池比例，不冒充已裁决的唯一错误比例。
- 允许导入注明裁判模型和提示版本的外部 LLM 记录，与人工分开；没有新增付费 API 调用，也没有复现 FeedEval 训练评价器。
- 原始回答优先，不修复格式；缺失、重复 ID、坏 JSON 及额外 ID 留档。失败不提前删除。反馈/GEC 合法输出指标与全量覆盖率一起报告，不把评分特有的“4 分误差惩罚”套入其他量纲。
- GEC 全文参考自动提取编辑是本项目协议，不能宣称官方 BEA 逐句成绩。官方对齐 M2 另有入口，多参考由 ERRANT 比较。当前包缺带答案的纠错 test；需向 2 号取得，不拿训练集冒充。
- BERTScore 不默默截断长反馈；超过模型 token 上限停止并提示。尚未实现分块聚合。
- 匿名评审公用材料去掉显式模型元数据，完整预测留在私有清单；正文仍可能透露身份。批次指纹防止误混不同评审批次。
- 本轮没有调整合成/推理/训练/网页运行代码，没有改变 D 全量审核政策或擅自确认采样与训练预算。

## 5. 验证结果

- 在独立 Web 环境运行全套 unittest：120 项，119 通过，BERTScore 可选依赖测试明确跳过 1 项。包含现有网页、合成和评分回归。
- 在独立评测环境运行评分/反馈/GEC 测试：36 项通过，使用真实 rouge-score、SacreBLEU、ERRANT 与英文 spaCy 模型。
- BERTScore 测试另外实际通过：本地临时构造微型随机 BERT，验证真实库调用和长文本拒绝，不下载大模型、不证明语义评价质量。结合两环境，120 项测试均有实际通过记录。
- 合成样例的命令行闭环通过：反馈相似度、全文纠错、M2 纠错、匿名材料生成、人工评分汇总。人工评分输入是明确标注的合成测试记录，不是实验人评结果。
- 验证依赖包括 rouge-score 0.1.2、SacreBLEU 2.6.0、ERRANT 3.0.2、spaCy 3.8.18、en_core_web_sm 3.8.0、bert-score 0.3.13、Transformers 4.57.6；环境使用 Python 3.12。
- 当前 Transformers 与 Web 的 Gradio 6.31.0 对 huggingface-hub 版本要求冲突，故隔离环境验证，未更改 requirements-web.txt。
- 测试/依赖安装在临时目录，生成报告未写入项目交付；没有进行 GPU 训练、真实教师生成或真实 A/B/C/D 模型评价。
