# 6号第三第四周系统交付

本轮完成 Qwen3-1.7B 模型 B 的本地接入口、桌面工作台、人评记录与测试材料。另协助5号完成C训练和A/B/C抽样自动评测；[实验复现入口](member5/abc-evaluation.md)与界面工作分别说明。当前人工评价使用20篇测试作文的A/B/C共60份匿名反馈，操作见[人工评价说明](human-evaluation.md)，真人分数尚未填写。

## 桌面工作台

独立窗口名称为“英语作文批改工作台”，沿用 Gradio 和 WebView2。模型来源可选择真实本地模型、共享团队 mock、展示样例和外部 JSON；后两类模拟来源不能保存为真实模型人评记录。六维标签为连贯性、句法、词汇、措辞、语法、规范，英文键保持一致。

配置 B 后默认选择真实本地模型；“本地模型试用”只加载作文，不预置答案。评分、反馈、纠错可独立勾选。失败任务保留原始回答和原因，其余合法任务继续展示。纠错全文用蓝底标出变化的句子；原文红黄绿仍只来自明确标注的展示样例，不伪称模型已生成错误定位。

各任务显示实际生成时间，模型加载与本次总处理另列。导出报告保留任务输出、失败、上下文预算、Adapter SHA-256 和实际运行环境。生成期间锁定相关输入；编辑作文、切换来源或任务会使旧报告失效。模型进程超时会终止，关闭桌面服务后其模型子进程也退出。

## 模型B与长度限制

B 为 Qwen/Qwen3-1.7B 的 LoRA Adapter。实际保存记录：1500 步、学习率 2e-5、microbatch 1、梯度累积 8、LoRA r=8/alpha=16、目标 q_proj/v_proj、max_length=512。根 Adapter 与 checkpoint-1500 一致，SHA-256 为 f0aa2f02396af98ed81c2f5deab794a2708dfe9033a35cb8eeda464cad48d95a。

实际 tokenizer 的 eos 为 151645 即 im_end；151646 为 object_ref_start。代码使用 enable_thinking=False，并核对真实结束符。关闭 thinking 和正确停止仅改善输出协议，不保证模型判断正确。

B 本机工作配置先限制 150 英文词，总预算 512 tokens，评分输出预留192、反馈256、纠错256。输入含任务指令及模板，真实 tokenizer 按项检查；词数合格仍可能超过 token 预算。超限拒绝对应任务、保留原文，不截掉作文或模型回答。较长纠错可能触及输出上限，应缩短作文。150 词是本轮短作文工作范围，不是训练512与英文词数的固定换算。

## GPU环境与配置

桌面 UI 与 GPU 推理使用独立 Python 环境。桌面发起本机隐藏工作进程，通过临时 JSON 文件交换报告，不开放外部网络推理服务；后台代码随桌面程序放在 backend 目录。每次请求加载模型并依次执行所选任务，模型准备时间因此包含在报告中。

安装 Windows CUDA 推理依赖时，先从 PyTorch 官方 CUDA 12.8 索引安装 torch 2.9.1，再安装 requirements-inference-worker.txt 中其余依赖。UI 环境安装 requirements-desktop.txt。两环境不共用 site-packages，评测可选依赖沿用团队 evaluation 环境约定。

```powershell
python scripts/configure_model_b.py --base-model "C:\models\Qwen3-1.7B" --adapter "C:\models\model_B_qwen3" --python-path "C:\envs\puyu-model\Scripts\python.exe" --desktop-dir "C:\apps\PuYu"
```

该命令生成 Git 忽略的本机配置，不将个人绝对路径写入公共配置。基础模型目录需有全部分片和 index，Adapter 目录需有权重及 tokenizer。模型 B 的小型 Adapter 不能单独代替官方基础权重。换电脑后需准备该电脑的推理环境并重新配置，不能只复制一个 EXE。

源码入口为 python run_desktop.py；打包入口为 python scripts/build_desktop.py。默认共享配置保持原始 A；模型 B 通过本机配置启用。下载原始模型的 prepare_web_model.py 已包含分片 index 文件。

## 人工反馈评价

“人工反馈评价”页显示当前真实报告的作文及反馈，四项质量分默认留空。评价者填写编号、分数、证据与可选逐项判断后保存 JSONL。修改有效性允许 N/A；失败输出的四项分数留空。虚构比例根据实际 valid/invalid 判断计算，并单列 uncertain 数，不从字符串匹配自动猜测。

该页能看见模型来源，因此属于署名系统复核。正式盲评使用 evaluation.feedback_review prepare 生成的 review_packets、独立评分模板和协调者 private_manifest；评价者不接收模型映射。至少两位评价者独立填写后使用 summarize 汇总，保留原始分歧。系统不自动填入真人分数。

本轮另提供可填写的TXT表。scripts/import_human_text.py 将真人填写的编号、日期、四维评分和证据转换为原有JSONL，校验冻结作文与反馈未被修改、输出编号完整且无重复；不自动补分。修改有效性N/A须有说明，失败输出分数留空。

早期5篇短验证作文的A/B试评单独保留。本轮人评已准备20篇测试作文、A/B/C共60份匿名输出；两位评价者各收到相同批次材料，失败输出保留且不打内容分。模型映射由协调者保管，真实评分由评价者独立填写。该范围仍属于抽样评价。
