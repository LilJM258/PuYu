# 人工反馈评价标准 v0.2（LEAF）

适用对象为 LEAF 格式反馈：同时阅读完整作文和 `feedback` 整段英文反馈，不要求模型给出 errors、引用位置或局部改法字段。本表评价反馈质量，不替代 ELLIPSE 作文六维人工标签。

正式评价前应固定样本、量表和统计口径，并通过模拟材料校准。配套示例仅解释记录方法，不代表真实模型盲评或独立双人评分结果。

## 1. 四项评价锚点

采用 1–5 整数，2、4 分为相邻锚点之间的情况。每项需记录原文或反馈中的具体证据；可由评价者给句子/判断编号，编号不是模型必填输出。

| 项目 / 记录键 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 问题识别准确性 problem_accuracy_1_5 | 大量误判，核心判断错误 | 部分正确，但有明显误判 | 提出的判断有依据，区分错误与可选润色；有根据的肯定也可得高分 |
| 建议具体性 suggestion_specificity_1_5 | 只有套话，不能指导阅读或修改 | 有针对性，但部分建议不清楚 | 具体结合文章内容、例子或语言现象，可理解并执行；不强制凑错误 |
| 修改有效性 edit_validity_1_5 | 多数建议错误、有害或改变原意 | 多数可用，部分不自然或解释不足 | 提出的改法/建议在上下文中正确、有效且保留原意 |
| 忠实于原文 faithfulness_1_5 | 多处虚构事实、曲解立场 | 部分解释偏离上下文 | 不补造事实，不改变观点或否定含义，评价有原文依据 |

没有具体改法或建议时，修改有效性可记 `null` 并说明原因；不能强行记满分或 0 分。若整份输出为空或格式失败，四项均记 null，并单独报告失败。没有明显语言错误时允许针对原文的肯定，不要求虚构问题。

问题识别准确性只评价反馈实际提出的判断。明显漏报写入 `missed_issue_notes`；没有完整参考标注，不称为召回率。

## 2. 虚构问题与人工判断

评价者手动标记反馈中可核验的判断/建议：反馈证据、对应原文依据、`valid / invalid / uncertain` 及理由。无需自动抽取 errors 数组，也不以字符串匹配代替语义判断。

- `invalid`：把正确表达判错、捏造原文事实、曲解观点，或提供明显有害改法。合理的可选润色属于 valid。
- `uncertain`：无法确认，需要复核，不能默认为正确。
- `hallucinated_error`：存在至少一条明确虚构问题/误判时 true；无明确误判且判断完成时 false；尚未核验或只有疑问时 null。
- 项目拟定“虚构/误判比例”=`invalid / (valid + invalid)`，同时报告已判定与 uncertain 数；分母为零记 null。判断拆分规则和汇总方式应在正式评价前固定，避免评价者拆分粒度不同。

此比例是本项目的操作性定义，不是自动引用匹配率。训练候选的 accept/reject 审核与测试集盲评记录分开保管；不能将此空表直接当成 D 数据已获人工接受的审核凭证。

## 3. 流程与一致性

1. 用三份模拟材料共同理解标准。至少两名评价者独立试填、讨论分歧，固定量表版本；校准记录与正式评价结果分开归档。
2. 正式评价使用 统一冻结的样本清单。训练、验证、测试用途分开；不因结果不好而替换测试作文。
3. 对同一篇作文的 A/B/C/D 输出使用匿名 output_id 并打乱顺序，模型映射由协调者保管，评价者不看组别。
4. 独立阅读原文和完整反馈，填写四项分数、证据、逐项判断、漏报说明和失败原因。
5. 任一维度相差 ≥2 分或 valid/invalid 相反时，讨论或请第三人裁决；保留双方原始记录，不覆盖。
6. 逐维报告有效评价数量、均值与离散程度，以及不适用数量、失败率、虚构问题及分歧。需要一致性指标时固定方法后计算；不预填统计结果。

## 4. 失败与其他任务

结构通过只证明 JSON 和字段符合约定，不能证明英文反馈正确、模型身份真实或评分准确。损坏 JSON、空反馈、生成失败均记录 `output_valid=false`、原始输出和原因，不只统计成功结果。

评分、反馈、纠错独立：评分失败不妨碍评价合法反馈。当前页面对一个评分任务要求六维全部合法后展示；自动评测程序按维度计分，两者口径不同。正式评分应使用未经页面修复的原始输出，页面不补分、不取整、不截断。

配套：`template.md`、`template.jsonl`、`calibration-example.md`。模板保留四项评分键；正式评价记录与校准记录分别汇总。
