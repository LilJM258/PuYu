# 核心训练数据 v1

本目录可整体拖入 GitHub 网页上传框，所有单文件小于 25 MiB。仅含同一批数据的一种 messages 表示，不要再混加完整包里的 mixed 或分任务数据。

## 文件

- train-00001.jsonl、train-00002.jsonl：共 9252 条训练样本，必须一起读取。
- validation.jsonl：1011 条验证样本。
- test.jsonl：3070 条带答案的评分/反馈测试样本；不含带答案的纠错测试样本。
- 数据许可说明.md：保留原作者许可、使用和引用说明。

每行包含 id、task、source、split、schema_version 和 messages。messages 中 user.content 是英文任务指令及原文，assistant.content 是 JSON 答案字符串。评分为六维原始小数；反馈仅人工反馈；纠错为完整作文。

## 读取训练数据（Python 标准库示例）

```python
import json
from pathlib import Path
folder = Path('training_data_v1')
train = []
for path in sorted(folder.glob('train-*.jsonl')):
    with path.open(encoding='utf-8') as stream:
        train.extend(json.loads(line) for line in stream if line.strip())
assert len(train) == 9252
# 将每条 record['messages'] 交给训练端分词/格式转换。
```

本文件夹提供训练输入数据，不含训练程序或模型权重。4 号仍需适配 Qwen Base 的输入模板、EOS、assistant-only loss、长度和训练参数，先做小规模试跑。不能假定 Base 自带可用 chat_template。训练集用于训练，验证集用于选择配置；测试集不能用于训练或调参。
